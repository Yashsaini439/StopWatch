# ⏱ Stopwatch Web App

A clean, responsive, and modern stopwatch web application built with HTML, CSS, and vanilla JavaScript. Features a sleek dark-mode UI with smooth lap recording and real-time interval updating.

---

## ✨ Features

- **Start / Stop Functionality:** Toggle the timer with live UI state updates.
- **Lap Tracking:** Record precise lap times on the fly without interrupting the main timer.
- **Fixed UI Layout:** Scrollable lap history prevents layout shifts or button shifting when appending lap entries.
- **Reset Capability:** Clear recorded lap times and reset the timer back to zero when paused.
- **Modern Dark UI:** High-contrast dark theme built with glassmorphic accents, subtle glow effects, and monospaced typography for high readability.

---

## 🛠️ Built With

- **HTML5** – Structural markup and accessible element labeling.
- **CSS3** – Custom styles, Flexbox layout, scrollable views, and modern dark aesthetics.
- **JavaScript (ES6)** – DOM manipulation, time formatting calculations, and state management via `setInterval`.
- **Google Fonts** – [`JetBrains Mono`](https://fonts.google.com/specimen/JetBrains+Mono) for numeric display and [`Inter`](https://fonts.google.com/specimen/Inter) for clean UI labels.

## 🚀 Getting Started

### Prerequisites

No external dependencies or installations are required! All you need is a web browser.

## 💻 How to Run Locally
### Installation & Execution

1. **Clone the repository:**
   git clone https://github.com/Yashsaini439/StopWatch.git

2. **Navigate into the directory:**
   cd StopWatch

3. **Open the project:**
   Simply Double-click index.html to open and run the application directly in your web browser.
